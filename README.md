# A Little Letter for Nira

A responsive React birthday-letter experience built with Vite and CSS.

## Requirements
- Node.js 18 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Customize
- Edit the birthday message in `BirthdayLetter` inside `src/App.jsx`.
- Change colors and responsive styles in `src/styles.css`.
